Movie_Verse
This is a web application for exploring and managing movies, built with React, TypeScript, Tailwind CSS, and shadcn-ui. Users can browse movies, view details, and save their favorites with a modern, user-friendly interface.
Features

Browse a collection of movies with titles, genres, and descriptions.
View detailed movie information, such as release year and ratings.
Save favorite movies to a personal list.
Responsive design for desktop and mobile devices.

Technologies Used

React: For building the interactive user interface.
TypeScript: For adding type safety to the code.
Tailwind CSS: For styling the app with a modern, cinematic design.
shadcn-ui: For pre-built UI components like buttons and cards.
Vite: For fast development and building the app.

How to Run the App Locally
To try the app on your computer, follow these steps:

Clone the repository:git clone https://github.com/Luser408/Movies_Verse.git


Navigate to the project folder:cd Movies_Verse


Install dependencies:npm install


Start the app:npm run dev


Open your browser and go to http://localhost:5173 to see the app.

Note: You’ll need Node.js installed. You can get it using nvm.
