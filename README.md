🎬 Movie_Verse
Welcome to Movie_Verse, a sleek web application for movie lovers! Built with React, TypeScript, Tailwind CSS, and shadcn-ui, this app lets users browse movies, view details, and save favorites with a modern, cinematic interface that shines on both desktop and mobile.
✨ Features

Browse Movies: Explore a collection of movies with titles, genres, and descriptions.
View Details: Check out release years, ratings, and more for each movie.
Save Favorites: Build a personal list of your favorite films.
Responsive Design: Enjoy a seamless experience on any device.

🛠️ My Contributions

Planned the Vision: Defined key features like movie browsing and favoriting to create a user-friendly app.
Styled with Flair: Customized Tailwind CSS to give the app a unique, cinematic dark theme.
Enhanced UX: Tweaked the layout for smoother navigation and a polished look.
Tested & Debugged: Ensured movies load correctly and the app runs flawlessly.

🚀 Technologies Used

React: Powers the dynamic, interactive user interface.
TypeScript: Adds type safety for robust code.
Tailwind CSS: Crafts a stunning, cinematic design.
shadcn-ui: Provides pre-built components like buttons and cards.
Vite: Enables fast development and builds.

📖 How to Run Locally
Want to try Movie_Verse on your computer? Follow these steps:

Clone the Repository:git clone https://github.com/Luser408/Movies_Verse.git


Navigate to the Folder:cd Movies_Verse


Install Dependencies:npm install


Start the App:npm run dev


Open your browser and visit http://localhost:5173.

Note: You’ll need Node.js installed.
